# Workflow

La única fuente del ciclo de trabajo es la skill [orchestrator](../../stack/skills/orchestrator/SKILL.md). Preparación de artefactos: [to-spec](../../stack/skills/to-spec/SKILL.md); revisión por riesgo: [xreview](../../stack/skills/xreview/SKILL.md).

Estas referencias son el canon instalable, no otro manual paralelo. PRD fija alcance, plan es el único tablero y tasks Markdown contienen specs; Engram conserva historia/decisiones, no otra copia de tareas. [Reglas locales del repo](../../AGENTS.md) · [testing](testing.md).
